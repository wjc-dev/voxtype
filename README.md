# VoxType for macOS — Qwen / Doubao

[English](./README.en.md) · 简体中文

不切换系统输入法的 macOS 语音输入工具。搜狗等拼音输入法可以一直保持为当前输入源；按住全局快捷键说话时，千问或豆包的累计结果显示在固定的胶囊浮窗中，松开后只向原输入框提交一次最终文字。

## 这个工具解决什么

很多用户喜欢用搜狗输入法打字，但又偶尔需要语音输入。如果装千问输入法 / 豆包输入法来获得语音能力，就必须切走搜狗。VoxType 把语音识别做成一个**独立的语音速记工具**：

- 不注册成系统输入法，不会动你当前的拼音输入法
- 按住快捷键说话 → 松开后把识别结果粘到光标处
- 支持千问 Audio 3.0 ASR Streaming 和豆包 Seed ASR 2.0 两个引擎
- 不依赖目标 App 的 Accessibility 接口，对微信 4.x、VS Code 等"封闭 AX"的应用也工作

## 当前能力

- 可选千问 Qwen Audio 3.0 ASR Streaming 或豆包 Seed ASR 2.0；默认千问
- 识别词汇同时适配两个引擎；豆包可选绑定控制台热词表 ID
- 右 Option、Fn/Globe、右 Command、自定义组合键；支持不会吞键的只读监听
- 企业兼容组合键 `⌃⌥Space` 由 macOS 单独注册，不读取其他按键且无需输入监控权限
- 点击菜单栏图标只会打开设置，不会启动或停止录音
- 浮窗默认固定在主屏底部居中（避开 Dock），需要跟随光标设环境变量 `VOICE_INPUT_FLOATING_FOLLOW_CARET=1`
- 最终结果只提交一次；录音中切换窗口时不会向新窗口误输入
- **盲 Cmd+V 路径**：拿不到目标 App 的 AX 锚点时（微信、VS Code 4.x），自动走 `⌘V` 兼容粘贴，仍能完成输入
- 兼容优先的临时剪贴板粘贴；恢复原内容并标记为短暂/保密，不会模拟 Return 或自动发送消息
- 极短按、静音和个性化上下文回显安全门
- 写入失败时可在本地保留最近 5 条恢复记录
- SwiftUI 原生设置、菜单栏常驻、无 Python 的内测 App/PKG 构建

本工具刻意**不**实现系统输入法的 marked text 下划线。那需要把自己注册成一个 InputMethodKit 输入源，会与"搜狗始终保持当前输入法"的目标冲突。当前设计把流式变化限制在独立胶囊里，目标编辑器只接收稳定的最终结果。

## 普通用户安装

推荐使用 `VoxType-v0.1.0-macOS-arm64-internal.dmg` 或 `.pkg`。它们内置运行环境，不需要 Python、Homebrew 或终端。无 Developer ID 时，App 本体采用 ad-hoc 签名，PKG 安装器容器不签名，首次启动需在 VoxType 的权限引导页按系统提示授予麦克风、辅助功能，以及单修饰键所需的输入监控权限。

首次打开后：

1. 在"引擎"页选择千问或豆包并填写自己的凭证；默认千问，专业术语或小声场景建议先试豆包。
2. 普通 Mac 可选右 Option；公司管控 Mac 建议使用 `Control + Option + Space`。
3. 点击"保存并重启"。
4. 把光标放进输入框，按住键盘右侧的 Option 说话，松开提交。企业安全软件阻止右 Option 时，在设置中改用 `⌃⌥Space` 组合键。

## 从源码运行

需要 macOS 13+、Apple Silicon、Xcode Command Line Tools、Python 3.13。

```bash
git clone https://github.com/WangJincheng888/voxtype.git
cd voxtype
uv venv --python 3.13 .venv           # 或 python3.13 -m venv .venv
uv pip install -r requirements.txt     # 或 pip install -r requirements.txt
cp env.example .env                    # 然后填入你自己的千问或豆包 API 凭证
.venv/bin/python main.py
```

## 构建可分发的 .dmg / .pkg

```bash
zsh ./build-internal-dmg.command
# 产物在 dist-internal/VoxType-v0.1.0-macOS-arm64-internal.{dmg,pkg,zip}
```

构建需要联网下载 PyInstaller 和 Swift 编译 native settings helper。


## 隐私设计

- **不上传录音**：默认关闭本地录音存档；开关在设置里
- **不记录识别内容**：日志只记 coarse 指标（字符数、是否写入），不存识别文本、上下文、目标 App
- **临时剪贴板**：识别结果写入时标记 `org.nspasteboard.TransientType` / `ConcealedType` / `AutoGeneratedType`，请求剪贴板历史工具不收录
- **API 凭证**：保存在 `~/Library/Application Support/VoxType/.env`，**不会**进入构建产物
- 语音数据按所选引擎送千问 / 豆包云端做识别；如果你的会话内容敏感，请使用企业自部署的 ASR 端点

## 已知边界

- macOS 26 Tahoe 上 Electron 应用（VS Code、Cursor 等）的 Accessibility 行为有回归。VoxType 在拿不到 AX target 时自动走"盲 Cmd+V"路径，结果仍能粘到前台窗口，但失去精确光标定位和去重
- 微信 4.x 完全关闭了 AX 暴露，同样依赖盲 Cmd+V 路径
- 不实现 marked text 下划线，这是刻意设计取舍
